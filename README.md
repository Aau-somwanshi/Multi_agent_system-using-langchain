# Multi_agent_system-using-langchain
# 🤖 Multi-Agent Research System

A full-stack, automated research pipeline powered by LangChain and Google Gemini models, designed to autonomously search, read, synthesize, and critique deep-dive reports on any topic via a clean Streamlit user interface.

## ✨ Key Features
- **Multi-Agent Architecture**: Modular pipeline featuring specialized agents for Searching, Reading/Scraping, Writing, and Critiquing.
- **LLM Integration**: Powered by Google Gemini (`gemini-1.5-flash` / `gemini-3.5-flash`) via `langchain-google-genai`.
- **Autonomous Web Research**: Integrates Tavily Search API to pull real-time web sources and documentation.
- **Interactive Web UI**: Built with Streamlit for a responsive, step-by-step visual tracking experience.

## 🛠️ Tech Stack
- **Framework**: LangChain, Python
- **AI / LLM**: Google Gemini API
- **Search Engine**: Tavily API
- **Frontend / UI**: Streamlit
- **Environment Management**: Python-dotenv
